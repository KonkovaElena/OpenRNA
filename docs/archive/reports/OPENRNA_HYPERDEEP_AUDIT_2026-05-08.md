## External Fact-Check Sources

- eCFR 21 CFR Part 11: authoritative current text for electronic records/signatures, including §11.10, §11.50, §11.70, §11.100, §11.200, and §11.300.
- FDA 2003 guidance, *Part 11, Electronic Records; Electronic Signatures — Scope and Application*: supports narrow, predicate-rule-aware Part 11 interpretation and emphasizes validation, audit trail, record retention, copies, and legacy-system controls.
- FDA 2024 procedural revision, *Electronic Systems, Electronic Records, and Electronic Signatures in Clinical Investigations: Questions and Answers*: confirms current FDA framing for electronic records/signatures in clinical investigations.
- OWASP API Security Top 10 2023 and OWASP WSTG API Broken Object Level Authorization guidance: validates the need for object/case-level authorization checks beyond route-level role checks.
- NIST SP 800-218 SSDF v1.1 / NIST software supply-chain attestation guidance: supports high-level artifacts, SBOM/provenance, and secure development evidence as supply-chain controls.

## Remaining Honest Gaps

- No signed IQ/OQ/PQ execution record has been produced on a target/production-representative PostgreSQL environment.
- OQ evidence must be generated by running `npm run test:oq-evidence` on the validated target environment, not by reusing local development logs.
- PQ scenarios still require real PostgreSQL concurrency/restart behavior, OIDC/JWKS integration, and FHIR round-trip validation.
- Regulated use still requires site SOPs for IdP onboarding, access reviews, retention/backup/restore, NTP synchronization, release authority, and signature key management.
- OpenRNA remains a workflow/governance control plane and does not perform clinical neoantigen prediction or autonomous therapeutic decision-making.

## Auditor Disposition

Software hardening and documentation synchronization are materially improved. The project is stronger for technical diligence and pre-IND pathway planning, but it is not a validated regulated system until target-environment IQ/OQ/PQ execution and site procedures are completed and signed.
